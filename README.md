## 开源 Skill

把仓库首页的安装提示词复制给 Agent，即可开始安装。自有代码采用 MIT 许可。

### [Ye1 Meta｜系统综述与 Meta 分析](https://github.com/Nzjye1/ye1-meta-analysis)

从研究想法、题录、全文或研究级汇总数据出发，串起文献整理、Meta 分析、证据表图与可编辑英文 Word 草稿。

**Windows x64 / Apple 芯片 macOS 14+ · 支持本地文件与命令执行的 Agent**

[**查看功能与案例 →**](https://github.com/Nzjye1/ye1-meta-analysis) · [**Windows 安装 →**](https://github.com/Nzjye1/ye1-meta-analysis/blob/main/INSTALL.md) · [**Mac 安装 →**](https://github.com/Nzjye1/ye1-meta-analysis/blob/main/INSTALL-MAC.md)

### [Ye1 临床分析 Skill](https://github.com/Nzjye1/ye1-clinical-research-skill)

提供本地 CSV 和研究问题，让 Agent 完成基线描述、关联、生存、预测等统计分析，生成结果表图与说明。

**Windows x64 / Apple 芯片 Mac · Codex · v0.3.0**

[**查看功能与案例 →**](https://github.com/Nzjye1/ye1-clinical-research-skill) · [**Windows 安装 →**](https://github.com/Nzjye1/ye1-clinical-research-skill/blob/main/docs/showcase/INSTALL.md) · [**Mac 安装 →**](https://github.com/Nzjye1/ye1-clinical-research-skill/blob/main/macos/INSTALL.md)

## 数据库科研 Skill

围绕不同研究领域，连接研究问题、数据库分析、结果表图与研究材料。

| 产品 | 研究方向与功能 |
|---|---|
| [**MIMIC＋eICU →**](https://github.com/Nzjye1/Nzjye1/blob/main/products/mimic-eicu.md) | 面向重症临床研究，开展队列构建、结局分析与预测研究。 |
| [**FAERS＋JADER →**](https://github.com/Nzjye1/Nzjye1/blob/main/products/faers-jader.md) | 面向药物安全性研究，组织不良事件与安全性信号分析流程。 |
| [**NHANES＋CHARLS＋KNHANES →**](https://github.com/Nzjye1/Nzjye1/blob/main/products/nhanes-charls-knhanes.md) | 面向人群健康、营养与慢病研究，选择数据库开展分库分析与结果对照。 |
| [**INSPIRE＋MOVER＋VitalDB →**](https://github.com/Nzjye1/Nzjye1/blob/main/products/perioperative.md) | 面向围术期临床研究，按研究问题选择数据源，生成分析、图表与研究材料。 |
| [**JAEB →**](https://github.com/Nzjye1/Nzjye1/blob/main/products/jaeb.md) | 面向糖尿病与连续血糖监测（CGM）研究，组织指标分析与写作流程。 |
| [**SEER →**](https://github.com/Nzjye1/Nzjye1/blob/main/products/seer.md) | 面向肿瘤队列、生存与预测研究，组织研究方案、分析图表与写作材料。 |
