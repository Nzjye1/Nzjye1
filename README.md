### 当前项目

**[Ye1 · 医生的科研全流程 Skill](https://github.com/Nzjye1/ye1-research-skills)**

为医生把研究想法或已有数据，逐步推进为方案、分析、图表和中英文论文审阅稿。

**1 个总流程 + 37 个专项，共 38 个入口**，可按任务单独调用，也可衔接完整流程。

- **从已有数据出发**：梳理研究目标与数据质量，推进分析、图表和论文初稿。
- **从临床问题出发**：明确研究问题，形成研究设计与 CRF（病例报告表），再衔接数据分析。
- **只做眼前一件事**：论文精读、文献核验、统计绘图、论文润色等，按材料与环境选择对应入口。
