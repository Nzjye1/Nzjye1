# SEER 肿瘤研究 Skill

**从癌种与研究问题，到生存分析、图表与可编辑文章。**

面向使用 SEER 导出数据的医生、流行病学研究者和统计团队。按癌种、年份和实际导出字段选择研究路线，确认方案后完成本地分析、结果表图、英文 Word 和后续修订。

## 适合什么需求

- 肿瘤队列的描述、关联与生存研究。
- 具备死因分类和明确定义的竞争风险研究。
- 基于适用字段开展记录级 Cox 预测与评价。
- 根据癌种、组织学、年份和导出版本核对临床字段。
- 将已有结果组织成文章，并保留结果与稿件的版本关系。

## 主要分析模块

| 方向 | 具体内容 |
|---|---|
| 队列与基线 | 研究单位、纳排、样本流程、基线与缺失规则 |
| 基础生存 | Kaplan–Meier、适用条件下的 Cox、预设亚组和敏感性分析 |
| 竞争风险 | 按明确事件与竞争事件定义生成累计发生率和 Fine–Gray 分析 |
| 预测评价 | 记录级 Cox 预测、分组隔离拆分、校准与决策曲线 |
| 临床字段适配 | 按导出版本、癌种、组织学及年份核对分期，以及部分分级、手术字段 |
| 写作修订 | 聚合结果进入英文稿，核对数字与引用，输出 Word 与新版本修订稿 |

## 你需要准备什么

- 合法可用的 SEER 导出数据及数据字典。
- 癌种、组织学、年份和所用导出版本。
- 人群、结局、事件与删失定义，关注的比较或预测问题。
- 参考文献、已有方案或待修改的文章。

研究开始时，Agent 根据实际字段判断路线，并把纳排、时间、协变量和缺失处理组织进方案。

## 典型流程

**研究问题与近邻文献 → 癌种/年份/字段可行性 → 确认方案 → 队列与分析 → 图表与解释 → 英文 Word → 修订**

> 请使用 SEER 研究 Skill。我关注：[癌种与问题]，数据为：[年份、导出版本与位置]。先核对字段和可行路线，形成研究方案；确认后完成队列、相应生存或竞争风险分析、表图与英文稿。

已有文章可以这样继续：

> 沿用当前方案和聚合结果，补充讨论与文献，输出新版本 Word，并保留原稿和修改记录。

## 能得到什么

- 研究方案、队列流程、变量与结局定义。
- 基线、模型、预设亚组与敏感性结果。
- 适用的生存、累计发生、校准和决策曲线。
- 与数字和方法对应的英文 Word、参考文献材料及修订稿。
