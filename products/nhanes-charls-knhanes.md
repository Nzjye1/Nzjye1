# NHANES＋CHARLS＋KNHANES 三库研究 Skill

**在统一入口组织人群健康、营养与慢病研究。**

围绕同一个研究问题选择合适数据库，完成单库分析，或按共同研究思路开展两库、三库平行复核，再整理结果图表与英文文章。

## 适合什么需求

- 人群健康、营养、代谢、生活方式与慢病相关问题。
- 已有基础文献，希望在适合的人群数据库中开展研究。
- 同一问题需要多个数据库分别分析、对照结果。
- 已有分析结果，需要整理研究方案、图表、文章和修订稿。

## 数据与功能范围

| 数据库 | 当前资料范围与使用方式 |
|---|---|
| NHANES | 多周期主题表快照；按课题选择周期、变量与对应分析定义 |
| CHARLS | 约 2011—2020 年第 1—5 波资料；按波次与研究问题组织分析 |
| KNHANES | 原始 SAS 快照最晚至 2024 年；目录驱动的数据入口，按年份与字段组织研究 |

可查找的人口学、体格、血压、代谢、营养、生活方式，以及部分功能与心理条目，按实际数据库和周期核对。

**三库平行研究保留各库自己的样本与分析口径。** 先判断变量定义、年份与研究设计是否适合比较，再形成分库结果与统一展示。

## 主要工作模块

- 研究方向与基础文献梳理。
- 数据库、周期/波次、字段与样本可行性核对。
- 研究方案、纳排、变量和分析定义组织。
- 单库描述与关联分析。
- 已确认方案下的双库或三库平行执行、分库汇总。
- 结果图表、英文 Word 草稿、后续修订与写作交接。

## 你需要准备什么

1. 想回答的研究问题，以及可供参考的文章或已有方案。
2. 关注的暴露、结局、人群和时间范围。
3. 使用的完整产品资料及数据位置；需要自备或补充的数据按对应交付说明准备。
4. 本机系统、芯片类型和可操作本地文件的 Agent。

基础数据按产品交付清单管理。课题开始前，Agent 再核对本题实际用到的年份、字段、权重和来源。

## 典型流程

**研究问题 → 文献与数据库选择 → 字段及样本核对 → 确认方案 → 分库分析 → 结果对照与图表 → 英文稿与修订**

> 请使用三库研究 Skill。我的问题是：[问题]，参考文献是：[文献]。先判断 NHANES、CHARLS、KNHANES 哪些适合这个问题，说明对应年份、字段和分析口径，再形成方案。按确认的方案分库分析，最后整理结果对照、图表和英文稿。

## 能得到什么

- 研究方案、变量定义、样本流程。
- 各数据库对应的分析结果与汇总图。
- 跨库结果对照及解释材料。
- 英文 Word 草稿、修订稿和写作交接资料。

## 已有应用材料

KNHANES 目录入口已有真实年份字段检查与营养分析材料，涉及 2022 年字段及 2008、2021 年营养数据处理。三库流程已形成分库汇总、图表与写作交接材料；展示时按各案例的真实或合成输入分别标注。

## 系统与使用方式

现有资料提供 Windows 与 Apple Silicon Mac 版本，Mac 的具体系统要求按所交付版本指南核对。Codex 本地项目方式已有工程使用记录；其他 Agent 需要具备本地文件读取、命令执行和项目说明遵循能力。
