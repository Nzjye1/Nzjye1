# INSPIRE＋MOVER＋VitalDB 围术期研究 Skill

**从围术期研究方向，到数据分析、图表与可续改 Word。**

在本地 Agent 中打开项目，说明研究方向和数据位置，由 Agent 检查数据、查证文献、准备方案，并调用对应来源已支持的分析路线。

## 适合什么需求

- 围术期临床变量、记录麻醉或手术间隔相关研究。
- 对适合的连续或二分类结局开展预测分析。
- 静态临床特征分型，或 INSPIRE 注册生命体征的固定窗口特征分析。
- 组织跨来源平行研究、结果解释和研究文章。

## 三个来源分别能做什么

| 来源 | 已有研究入口 |
|---|---|
| INSPIRE | 流式读取、临床字段描述、记录手术间隔与麻醉时长、患者分组连续预测、静态分型、注册生命体征固定窗特征 |
| MOVER EPIC | 临床表及关联表读取、部分 cleaned 测量字段、记录 OR 间隔描述与关联、记录麻醉时长、共同静态特征固定派分 |
| VitalDB | 临床静态表、记录 ICU 天数关联、连续/阈值预测及静态分型 |

INSPIRE/MOVER 已有**记录麻醉时长的两库平行关联**路线，以共同支持的 ASA I–V 与性别组织分析。两库独立估计，保留各自研究单位和时间含义。

## 分析模块

- **预测：** Ridge 线性与 Ridge Logistic，患者分组训练/验证、训练内交叉验证及预处理，输出适合结局的误差或判别、校准和不确定性。
- **静态分型：** KMeans，以及适合连续特征的对角协方差 GMM；训练来源内完成预处理、选 K 与稳定性分析，跨来源使用冻结模型。
- **固定窗口特征：** INSPIRE 注册生命体征按预设时间窗生成覆盖率、测量数量与趋势特征，再开展可复核分型。
- **研究写作：** 文献与主张核对、聚合结果整理、Word 输出及保留旧稿的续改。

## 你需要准备什么

- 围术期研究方向、关注结局和参考文献。
- 合法可用的数据及本地位置。
- 研究单位、时间窗、预测时点或比较目标。
- 电脑系统与能够读取文件、运行本地程序的 Agent。

## 典型流程

**环境准备 → 来源与字段核对 → 文献和候选问题 → 确认方案 → 分析与图表 → 结果解释 → Word 与续改**

## 能得到什么

- 研究方案、队列与字段说明。
- 关联或预测结果、适用的分型与固定窗口特征报告。
- 汇总表、森林图或相应预测/分型图。
- 参考文献材料、可编辑 Word 与修订记录。

## 已有真实数据案例

- **INSPIRE/MOVER：ASA 与记录麻醉时长。** 已有两库独立关联与敏感性分析，形成 4 图、5 表及英文样稿；采用性别调整，按观察性关联解释。
- **VitalDB：记录 ICU 天数预测。** 展示患者分组内部留出、训练内处理、校准与常数对照的完整评价流程。

## 系统与使用方式

提供 Windows x64 和 Mac arm64 的本地项目资料。Windows 包含 Python 与锁定依赖；Mac 按对应说明准备指定 Python 与隔离依赖。Word 由程序生成，无需依赖 Office 界面操作。
