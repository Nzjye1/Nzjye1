# FAERS＋JADER 药物安全研究 Skill

**把药物安全性问题，推进到双库信号分析、图表与研究稿。**

输入药物、药物类别、不良事件或临床疑问，由本地 Agent 协助核对名称、整理文献、确认研究定义，完成单库或双库分析与写作。

## 适合什么需求

- 一个药物或药物类别与指定不良事件的报告信号研究。
- 在预设的有限药物—事件组合中开展对照。
- 两库平行分析，或在主库发现线索后到另一库复核。
- 根据已有结果修改文章，或评估改变药名、事件与角色定义后的重算范围。

## 数据与研究路线

产品对应 FAERS 季度数据与 JADER 累计快照。每项研究固定自己的来源范围、药物角色、事件定义与背景集合。两库**分别分析，再对照结果**。

| 模块 | 具体内容 |
|---|---|
| 药名与范围核对 | 整理成分、通用名、商品名、盐形式、歧义与复方范围，形成有来源的名称台账 |
| 单库与双库路线 | 单库研究、两库平行对照、发现—复核路线 |
| 常规统计 | 报告集合与四格计数、ROR/PRR 及 95% 区间、预设最小共现数与信号规则 |
| 来源与敏感性 | 来源年度、药物角色及已支持的人群/名称/事件定义场景 |
| FAERS 条件模块 | 显式请求时的 IC/BCPNN 正态近似；来源支持时的报告特征、分层分析和描述性 TTO |
| JADER 适配 | 累计 CSV 连接、报告内集合计数、粗 ROR/PRR、年度与角色场景及已配置来源限定 |

**ROR/PRR 描述报告不成比例关联；TTO 描述可计算日期子集中的报告时间间隔。** FAERS 条件模块按其来源字段启用，JADER 按自己的适配范围执行。

## 你需要准备什么

- 研究药物或药物类别、关注事件、比较对象与临床问题。
- 数据快照及本地位置，或已经完成的研究结果。
- 拟用的时间范围、药物角色、人群与事件口径。
- 可补充的方案、参考文献、药品资料、旧稿与语言要求。

## 从问题到交付

1. **项目准备：** Agent 检查本地材料、环境、来源与数据位置。
2. **问题与文献：** 讨论少量候选问题，明确临床需求。
3. **名称与可行性：** 核对药物写法、事件、角色、背景与覆盖情况。
4. **方案与分析：** 固定范围后计算四格和统计量，按路线做对照。
5. **结果与写作：** 解释表图，把同一版本的统计结果组织进稿件。
6. **修订：** 文字与文献修改可复用结果；定义变化先评估需要重算的部分。

## 能得到什么

- 研究方案、药名覆盖台账与来源定义。
- 完整四格与统计表、年度和适用的敏感性结果。
- ROR 森林图、来源年度图、双库信号状态对照及适用扩展图。
- 文献记录、段落证据、Word/HTML 稿件与修订版本。

## 可以这样开始

> 我关注：[药物/药物类别] 与 [不良事件]。请使用 FAERS＋JADER Skill，先检查数据范围、核对药物名称与角色，结合文献给我研究方案。方案确认后分别分析两库，展示四格、ROR/PRR、区间与结果对照，再组织文章。

也可以直接接着已有研究：

> 保留现有研究定义和结果，只补充讨论的文献证据，输出一个新的修订稿。
