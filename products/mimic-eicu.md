# MIMIC＋eICU 研究 Skill

**从 ICU 临床问题，到双库分析、表图与可续改的研究稿。**

这是一套供本地 AI Agent 使用的 MIMIC-IV 与 eICU 研究工具。给出研究方向后，Agent 协助查找文献、检查字段和时间定义、整理研究方案，再执行相应分析并组织结果与文章。

## 适合什么需求

- ICU 数值检验与院内结局的关联研究。
- 在 MIMIC 中开发模型，再将固定模型应用于 eICU。
- 按预设时间窗研究检验值变化，或对实验室特征做固定分型。
- 研究指定观察界点之后的记录医院退出与竞争事件。
- 在已有结果基础上补文献、调整讨论和输出新版本文章。

## 数据与分析模块

数据入口对应 **MIMIC-IV 3.1 与 eICU CRD 2.0**。两库保留各自人群与来源，按问题选择分库关联或固定模型迁移。

| 模块 | 具体做什么 | 主要产物 |
|---|---|---|
| 关联分析 | Logistic MLE、患者聚类稳健推断、预设阈值与调整特征、完整病例及阈值敏感性 | 两库 OR、置信区间与关联结果表 |
| 预测分析 | L2 Logistic；MIMIC 按患者拆分；训练内插补与标准化；固定后应用 eICU | AUROC、AUPRC、Brier、校准、ROC/PR 与适用的决策曲线 |
| 规则分窗轨迹 | 2—8 个预设连续观察窗，计算窗中位数与首末净变化分组 | 覆盖情况、分组表、窗内中位数/IQR 与聚合轨迹图 |
| 实验室分型 | 冻结 KMeans；训练中学习预处理与质心，再对内部及 eICU 固定赋型 | 类规模、特征分布、质心热图与赋型比例 |
| 生存与竞争事件 | 指定 landmark 后的原因别 Cox 与 Aalen–Johansen；记录死亡退出和存活退出 | 原因别 HR、累计发生曲线与相应区间 |

规则轨迹按明确的变化规则分组；生存路线的结局是指定观察界点后的**记录医院退出**。每条路线均围绕选定时间窗与结局解释。

## 你需要准备什么

1. 临床方向，或已有方案、参考文献、结果与旧稿。
2. 合法可用的对应版本数据及其本地位置。
3. 关注的人群、暴露或特征、观察时间窗、结局。
4. 文章语言与希望得到的交付材料。

Agent 会进一步核对患者/住院层级、字段映射、单位、缺失与时间可用性，将这些定义写进方案。

## 典型使用流程

**准备环境与数据 → 查文献、讨论问题 → 双库可行性 → 确认方案 → 分库分析或固定迁移 → 解释表图 → 写作与修订**

先打开完整项目目录，把准备工作交给 Agent：

> 请加载这个目录里的 MIMIC＋eICU Skill，检查环境和配套数据，准备项目环境。我的研究方向是：[方向]。先核对文献、人群、字段、时间窗与结局，给我研究方案，再按确认的方案分析。

结果出来后，可以继续：

> 沿用当前聚合结果，补充文献并修改讨论，生成新版本 Word 和表图，保留旧稿。

## 能得到什么

- 研究方案、数据定义与样本流程。
- 相应路线的聚合结果表、统计图和方法说明。
- 文献清单与段落证据记录。
- 可编辑 Word、Markdown、本地 HTML 及版本修订材料。

## 已有案例

- **肌酐关联专题：** 已有专题结果的聚合重导出，包含样条与敏感性结果、模型表、补充对比表和双面板森林图；专题方法按该方案使用。
- **常规化验预测：** 展示患者拆分、固定模型迁移、区分度与校准结果。
- **规则轨迹、实验室分型、竞争事件：** 分别展示窗中位数/IQR、冻结质心与赋型、累计发生曲线与 HR 表。

以上是不同研究路线的案例，不将其合并为一个研究结论。

## 系统与使用方式

提供 Windows 与 Apple Silicon Mac 的本地项目包。Windows 准备流程使用随包 Python/依赖并检查 PowerShell 7；Mac 使用本机原生 Python 与项目依赖。由具备本地文件读写及命令执行能力的 Agent 按包内说明完成准备。
