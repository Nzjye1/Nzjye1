# JAEB 糖尿病研究 Skill

**把糖尿病研究资料，推进到有来源的分析与英文研究稿。**

面向糖尿病技术、连续血糖监测（CGM）和相关临床研究。先将研究问题与来源、终点、访视及比较对象对齐，再调用已支持的路线，输出聚合结果与可编辑文章。

## 适合什么需求

- 已有 JAEB 研究资料，希望先检查来源和可计算字段。
- 围绕选定研究开展本地 HbA1c 探索性比较。
- 对指定 CGM 来源开展已有配置支持的数值描述。
- 将核对后的分析事实整理为英文稿，并继续补文献、修订讨论。

## 研究与模块

统一入口登记 **CITY、DCLP3、DCLP5、IOBP2、PEDAP、SENCE** 六项研究与 18 个配置，按研究、分析和 profile 选择。

| 来源或模块 | 当前支持内容 |
|---|---|
| CITY、DCLP3、DCLP5 | 选定来源质量检查与本地 HbA1c 探索性比较；CITY/DCLP3 对应 26 周访视标签，DCLP5 对应 16 周 |
| IOBP2、PEDAP、SENCE | 选定来源质量检查 |
| DCLP3 泵来源 | 单来源条件样本分布，按指定来源和配置解释 |
| PEDAP Clarity | 前缀数值描述 |
| 研究写作 | 聚合事实、分母与模型进入英文 Word，连接文献与修订流程 |

CGM 来源中的**样本数值分布**与按时间定义的指标分别组织；研究开始时先核对本题指标的计算定义。

## 你需要准备什么

1. 合法可用的 JAEB 资料及来源位置。
2. 目标研究、终点、访视和比较对象。
3. 关注的临床问题、参考文献或已有方案。
4. 希望输出的文章语言、表图和修订要求。

## 典型工作流程

1. **问题与文献：** 把想法整理为候选问题，核对相近研究和所需数据。
2. **来源与方案：** 选择研究、配置、终点、访视及比较对象，核对字段。
3. **本地分析：** 运行相应检查与统计，生成带来源、分母和模型的聚合结果。
4. **文章与修订：** 将核对后的事实组织为英文 Word，再按反馈补文献和修改。

> 请使用 JAEB 研究 Skill。我的资料来自：[研究与位置]，关注：[问题]。先检查来源、访视、终点和可用配置，给出方案；确认后执行对应分析，整理结果表图与英文稿。

## 能得到什么

- 研究与数据需求说明、已选配置和方案。
- 来源检查、聚合结果表及适用图件。
- 与结果对应的英文 Word 草稿。
- 文献补充、修订关系与新版本稿件。

## 展示材料

现有 DCLP3 **合成示例**用于展示分析到 Word 的流程与版式。实际使用从客户所提供的研究资料、终点和访视定义开始；示例不作为原试验疗效或论文复现案例。

Windows 与 Mac 均有 v3 本地包资料，按对应包内说明完成预检和环境准备，再选择研究路线。Mac 使用 arm64 对应环境。
